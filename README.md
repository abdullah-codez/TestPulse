# TestPulse

**Agentic QA Platform for AI-Built Applications**

TestPulse is a final-year project that operates alongside AI coding agents (Antigravity 2.0, Claude Code, Codex, etc.) and is invoked via the **Model Context Protocol (MCP)**. Instead of relying on superficial tests generated by the coding agent itself, TestPulse autonomously ingests a codebase, builds a structural AST knowledge graph, generates fresh test suites, executes them in isolated Docker sandboxes, and reports defects with evidence back to the coding agent.

## Quick Start

```powershell
# 1. Clone and navigate
cd d:\FYP\TestPulse

# 2. Create and activate virtual environment
python -m venv venv
.\venv\Scripts\Activate.ps1

# 3. Install TestPulse in editable mode
pip install -e ".[dev]"

# 4. Copy and configure environment
Copy-Item .env.example .env
# Edit .env: add your OPENROUTER_API_KEY and TESTPULSE_EMBEDDING_API_KEY

# 5. Run tests
pytest tests/

# 6. Start the API server
python -m testpulse.main
# Open http://localhost:8000/health
# Open http://localhost:8000/docs (OpenAPI)
```

## Architecture

TestPulse runs **natively on the Windows 11 host** in a Python `.venv`. Docker is used exclusively for on-demand ephemeral test sandboxes and Component 2 browser testing stacks — not for the TestPulse engine itself.

```
TestPulse (Native .venv)
├── FastAPI + uvicorn     — Dashboard & REST API
├── LangGraph             — Orchestration State Machine
├── Native AST Engine     — Tree-sitter + NetworkX Knowledge Graph
├── Code-Aware RAG        — Qdrant Local + Remote Embeddings
├── MCP Server (stdio)    — Coding Agent Interface
└── Test Pipeline
    ├── Context Gatherer (Graph + RAG)
    ├── Planner (Behavior Matrix)
    ├── Writer (Greenfield Test Synthesis)
    ├── Ephemeral Docker Sandbox (2GB RAM cap)
    └── Validator (AST Smells → exit_code → Mutation → Triage)
```

## Three Components

| Phase | Component | Scope |
|---|---|---|
| 1 | **Code-Level Testing** | Python/FastAPI/SQLite — fresh unit & integration tests |
| 2 | **Browser Testing** | Playwright E2E — React/Vite user flows |
| 3 | **Root-Cause Analysis** | Cross-layer frontend ↔ backend failure correlation |
